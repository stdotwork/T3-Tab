# t3-tab

The helper for [T3-Tab](https://github.com/stdotwork/T3-Tab), a browser extension that gives coding agents your own
browser as MCP tools.

```sh
npx t3-tab@latest setup      # install the helper for your user and register it with your browsers
npx t3-tab@latest uninstall  # remove everything setup added
```

Needs Node.js 20 or newer. See the project's README for what is installed and where.
